# Learning digital design (Basic)

A collection of RTL design projects focused on digital logic, hardware architecture, and verification.

## Focus Areas

* RTL design with Verilog-2001
* Combinational and sequential logic
* Digital system architecture
* Simulation and functional verification
* FPGA-oriented design and hardware implementation

## Featured Projects

### 1. 8-bit Arithmetic Logic Unit (ALU)

**Status:** In development

An 8-bit combinational ALU supporting arithmetic, bitwise, shift, and comparison operations.

* **RTL:** Verilog-2001
* **Verification:** Self-checking testbench and directed test cases
* **Simulation:** Verilator and GTKWave
* **Documentation:** Architecture, operation table, and verification results

[View project →](projects/alu8/)

## Tools

* Verilog-2001
* Verilator
* GTKWave
* VS Code

## Engineering Approach

Each project aims to include readable RTL, a documented interface, reproducible simulation, and verification evidence. Implementation claims and results will be documented as the projects mature.
